Scan it. Guard it. Scan it again.

Teste. Proteja. Teste de novo.

A public lab that shows the test–protect–retest cycle for a chatbot. NVIDIA Garak looks for weaknesses. NVIDIA NeMo Guardrails checks messages while the bot is in use. You run the scan a second time and compare the reports.

Um laboratório público que mostra o ciclo testar–proteger–testar de novo. O NVIDIA Garak procura fraquezas. O NVIDIA NeMo Guardrails confere as mensagens enquanto o bot está em uso. Você roda o teste outra vez e compara os relatórios.

The cycle

O ciclo

01 · Scan

Garak

A scanner you run before launch. It sends many test prompts to your own bot and records which answers look unsafe.

Um scanner que você roda antes de publicar. Ele envia vários testes para o seu próprio bot e registra as respostas que parecem inseguras.

02 · Protect

NeMo Guardrails

Live protection. Each message is checked on the way in and on the way out: policy, jailbreak hints, topic, and personal data.

Proteção ao vivo. Cada mensagem é conferida na entrada e na saída: política, sinais de jailbreak, assunto e dados pessoais.

03 · Retest

Compare

Comparar

The same scanner runs against the guarded bot. The difference between the two reports is the measurement.

O mesmo scanner roda contra o bot protegido. A diferença entre os dois relatórios é a medida.

Two tools, two jobs

Duas ferramentas, dois papéis

Garak

The inspector. It does not sit in front of users. You run it when you want a report: prompt injection, jailbreak, data leakage, toxicity.

O inspetor. Ele não fica na frente dos usuários. Você roda quando quer um relatório: injeção de prompt, jailbreak, vazamento de dados, toxicidade.

NeMo Guardrails

The door policy. It stays on in production and can block or mask a message before anyone sees a bad answer.

A política da porta. Fica ligada em produção e pode bloquear ou mascarar uma mensagem antes que alguém veja uma resposta ruim.

Stack

Pilha

  • Python 3.11–3.13
  • FastAPI 0.143
  • NeMo Guardrails 0.24.1
  • Garak 0.17.0
  • OpenAI-compatible API or Ollama
  • GitHub Actions · GitHub Pages

No NVIDIA GPU is required when the model is an API. A local model needs more RAM. On Windows, if pip stops while compiling a native extension, install the Microsoft C++ Build Tools and retry.

Não precisa de GPU da NVIDIA quando o modelo é uma API. Um modelo local pede mais memória. No Windows, se o pip parar ao compilar uma extensão nativa, instale o Microsoft C++ Build Tools e tente de novo.

How to run

Como executar

  1. Clone the repo and create a virtual environment with Python 3.11, 3.12, or 3.13.
  2. Clone o repositório e crie um ambiente virtual com Python 3.11, 3.12 ou 3.13.
  3. Copy .env.example to .env and set your model URL and key. Do not commit .env.
  4. Copie .env.example para .env e defina a URL e a chave do modelo. Não faça commit do .env.
  5. Install the lab packages, start the API, then scan before and after.
  6. Instale os pacotes do laboratório, suba a API e rode o scan antes e depois.
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lab.txt
cp .env.example .env
make serve
# second terminal, from the repo root
make scan-before
make scan-after
make compare

The local chat is at http://127.0.0.1:8000/ui. Leave the server on localhost. It has no login, and anyone who can reach it can spend your API key.

O chat local fica em http://127.0.0.1:8000/ui. Deixe o servidor em localhost. Ele não tem login, e quem conseguir acessá-lo pode gastar a sua chave de API.
